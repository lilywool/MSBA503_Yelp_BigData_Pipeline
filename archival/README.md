# Coursework archive

This archive preserves the parts of the original MSBA 503 project that explain
how the work developed, without publishing raw data, generated outputs, private
working notes, cloud credentials, or abandoned environments.

- `coursework_aws/` records the original AWS architecture and its relationship
  to the current implementation.
- `coursework_dashboard/` preserves the original team dashboard notebook and
  documents module ownership.

The live, maintained pipeline is at the repository root. Archived artifacts are
historical references and are not invoked by the Databricks or EMR jobs.
